This project compares sorting and searching algorithms.
I implemented Bubble Sort, Quick Sort and Linear Search.

Bubble Sort:
Compares and swaps elements.
Time complexity: O(n^2)

Quick Sort:
Faster algorithm using pivot.
Time complexity: O(n log n)

Linear Search:
Scans each item.
Time complexity: O(n)

Binary Search requires a sorted array because it divides the search space in half.
Without sorting, it cannot correctly eliminate elements.

Challenges:
- Understanding Quick Sort recursion
- Measuring time correctly
- Handling large arrays
